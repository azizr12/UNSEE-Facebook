# Unseen for Facebook

A small Chrome extension that prevents Facebook story view tracking.

## Features

- Prevents the Facebook story seen-state mutation from being sent.
- Works on Facebook and Messenger web pages.
- One simple setting in the popup.
- No icons, notifications, analytics, or external update service.
- Settings are stored locally in Chrome.

## Installation

1. Download latest zip release and extract its contents to folder
1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
5. Select the extracted repository directory.
6. ENJOY
